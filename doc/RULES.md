# RULES

- 语言要求：C++20
- 构建系统：cmake，多级构建（库、可执行文件、测试）
- 要求使用OpenMP并行
- 构建目标：为多物理场仿真库（而不是可执行文件，可执行文件应各自独立编译为目标）
- 必须使用日志系统而非原始的cout等。
- 使用Eigen库的向量、矩阵和稀疏矩阵类型，如果需要扩展或者别名，请直接使用继承或者别名，或者用pimpl技巧。不必自己封装。或者为了泛用性，你可以在Eigen库基础上封装张量类型。
- 测试应该从底向上，随着构建测试底层的网格读取、形函数计算（线性及二阶），积分，数值积分等，先把底层的有限元计算库测试稳定，再开始构建物理层。
- 实现并积极使用一个极简的线程安全的日志系统，便于后续调试。
- 详尽的文档记录，统一在doc/目录下，有序存放程序架构，计划，TODO等。
- 尽可能避免简化或者占位实现，保证程序的良好设计。对实现存在简化或者只是占位实现的地方，请加入TODO注释以说明。
- 严格禁止向后兼容。
- 任何情况下，逻辑嵌套必须少于三层。
- 代码越精简越好，抹除不必要的抽象。
- 尽可能少做判断，只在最接近用户层的地方做判断，减少热循环中分支预测代价。
- 所有同质功能的接口只保留一个性能最高、最易用的，使代码更清晰，不易误用。
- 禁止使用const_cast（除非为了调用外部求解器的局部使用），mutable（除非为了缓存或者锁），friend，dynamic_cast，shared_ptr等关键字或功能。
